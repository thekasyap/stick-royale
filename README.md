# Stick Royale

Lightweight, browser-playable stick-figure battle royale inspired by BGMI / PUBG.

**Stack:** Vite + TypeScript + Canvas client (Vercel) · Cloudflare Durable Objects for authoritative multiplayer rooms · Solo + bot-fill + VS AI difficulties.

## Status

Scaffolding and core systems are being built by a cloud agent. See the implementation plan in this repo as work lands.

## Local dev (soon)

```bash
npm install
npm run dev
```
